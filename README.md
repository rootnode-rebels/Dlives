# DLives — Your Windows Desktop, Alive. 🏝️✨

> **DLives** brings Apple-inspired Dynamic Island interactions to Windows 10 and 11. A sleek, translucent glass pill that rests at the edge of your screen — invisible when you're focused, alive when you hover.

## 🌟 Key Features

- 🏠 **Home Dashboard**: Quick glance at upcoming alarms, today's timetable, pinned notes, and a built-in Pomodoro focus timer.
- 🎛️ **Control Center & Media**: Native Windows SMTC integration for Spotify, YouTube, Chrome, Apple Music, plus CoreAudio volume & display brightness sliders.
- 📊 **System Diagnostics**: Real-time CPU, RAM, Wi-Fi, battery health, and one-click temporary cache cleaner.
- 📝 **Notes & File Sync**: Multi-note scratchpad auto-saving plain `.txt` files directly into `%AppData%\DLives\notes\` — no proprietary format locks.
- 📅 **Calendar & Events**: Monthly glassmorphism calendar with event tagging.
- ⏰ **Alarms & Timetable**: Multi-sound alarm picker with slide-in dismiss/snooze alert banners.
- 📋 **Clipboard & File Shelf**: History buffer with one-click re-copying and temporary drag-and-drop file staging.
- 🚀 **App Launcher**: Instant access grid for your most-used apps and terminal scripts.
- ⚙️ **Customization Studio**: Live color accents, Dark/Light modes, opacity/radius sliders, and full tab management.
