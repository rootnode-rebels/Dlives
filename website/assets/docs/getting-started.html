Getting Started with DLives

Follow this quick guide to install, launch, and configure DLives on your Windows 10 or 11 desktop.

System Prerequisites

Before installing, ensure your PC meets the minimum system requirements:

  • Operating System: Windows 10 (version 1903 or newer) or Windows 11 (64-bit).
  • Hardware: 100 MB available RAM, ~75 MB free storage space.
  • Permissions: Standard user account (Administrator privileges are not required).
  • Runtimes: None needed. DLives is fully self-contained.

Step 1: Download & Run Installer

1

Download the Installer

Download the latest setup executable (DLives_Setup_v1.0.exe) from the official GitHub Releases page.

2

Run the Setup Wizard

Double-click the installer. It installs per-user into %LocalAppData%\Programs\DLives\ without prompting for Windows UAC administrator elevation.

Step 2: Windows SmartScreen Notice

🛡️
Why does Windows show a blue warning? Because DLives is an indie project developed by Fugentech and the binary is not signed with an expensive commercial EV certificate, Microsoft Defender SmartScreen may display: "Windows protected your PC — Microsoft Defender SmartScreen prevented an unrecognized app from starting."

To continue the standard installation:

  1. Click "More info" directly under the alert text.
  2. Click the "Run anyway" button that appears in the bottom right corner.
  3. The installer will immediately launch. You only have to do this once.

Step 3: First Launch & Basic Usage

Upon launching DLives:

  • Floating Pill: A compact glass pill will dock at the top (or bottom) edge of your primary display.
  • Hover to Expand: Move your mouse pointer over the pill. It will expand smoothly with an animated Liquid Glass transition into the multi-tab productivity dashboard.
  • System Tray Icon: Look for the blue DLives icon in your Windows Taskbar notification area (tray). Right-click it at any time to toggle the island, open Settings, or exit.
  • Lock Triggering: Toggling Caps Lock or Num Lock will pulse the island badges and briefly surface status alerts.

Step 4: Permissions & Notification Stream

For DLives to display live notification banners and stream recent messages into the Notifs tab:

🔔
Enabling Windows Notification Listener Windows 10/11 may prompt to allow DLives access to your notifications. Click Allow. If you previously denied this or notifications do not appear:
Open Windows Settings → System → Notifications and ensure app notifications are enabled.

Data Storage & Privacy

All your user settings, notes, alarms, and calendar entries remain 100% offline on your device:

User Data Root: %AppData%\DLives\
├── settings.json       # Visual & behavior configurations
├── alarms.json         # Configured alarm triggers
├── calendar.json       # Date-bound calendar events
├── clipboard.json      # Captured clipboard items
├── timetable.json      # Recurring daily timetables
└── notes\              # Plain text (.txt) files readable directly in File Explorer
