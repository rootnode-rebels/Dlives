Features

Everything you need,
in one floating panel.

11 fully integrated tabs — each a focused tool, always one hover away.

🏠 Home Dashboard

Your day, at a glance

The Home tab greets you with a live overview: upcoming alarms, today's timetable, pinned notes, a Focus & Pomodoro timer, Now Playing media, recent notifications, and a Quick Drop Zone for files. You choose which cards appear.

  • Upcoming alarms summary
  • Today's timetable schedule
  • Pinned notes (up to 2)
  • Focus & Pomodoro timer
  • Quick file drop zone
🎛️ Control Center

Master your media & system

Full media transport hooked into Windows SMTC — controls Spotify, Chrome, VLC, YouTube Music, and any audio app. Plus system master volume and display brightness sliders, updated in real time.

  • Now Playing — title & artist
  • Play / Pause / Previous / Next
  • System master volume slider
  • Display brightness slider
⏰ Alarms & Timetable

Never miss a moment

Schedule alarms with a precise time picker, custom title, repeat days, and your choice of chime sound. When an alarm fires, a modal banner card slides in with dismiss or snooze. The Timetable sub-tab handles your recurring daily schedule.

  • Per-day repeat schedule (M–Su)
  • Custom alarm chime sounds
  • Modal banner alert on trigger
  • Daily timetable checklist
📅 Calendar & Events

Every date, organized

A full glassmorphism calendar widget right inside the island. Click any date to see and add events. Events persist locally as JSON — no Google account, no cloud, just your data.

  • Full monthly calendar grid
  • Per-date event list
  • Quick event creation
  • 100% local — no cloud sync needed
📝 Notes

Notes that live in File Explorer too

Create multiple named notes, write freely, and content auto-saves on every keystroke. Each note is a real .txt file in your AppData folder — open, edit, or share them directly from File Explorer. Pin your most important notes to the Home dashboard.

  • Multiple named notes
  • Auto-save on every keystroke
  • Real .txt files — not proprietary
  • Pin 2 notes to Home dashboard
📋 Clipboard & File Shelf

Never lose what you copied

Clipboard History automatically captures everything you copy. Re-copy any past entry with one click. The File Shelf is a drag-and-drop staging area for files you're moving between folders — like a clipboard, but for files.

  • Auto-capture clipboard history
  • One-click re-copy any entry
  • Drag-and-drop File Shelf
  • Persistent across sessions
📊 System Diagnostics

Your system, always monitored

Live CPU load, RAM usage, active Wi-Fi network, battery percentage, storage space, and system uptime — all updating every second. One-click temp file cleaner included.

  • CPU%, RAM (used/total), Disk
  • Active Wi-Fi + signal strength
  • Battery % + charging state
  • One-click temp file cleaner
🚀 App Launcher

Your apps, one hover away

A customizable icon grid for your most-used apps and executables. Add any custom app or shortcut and it pins instantly to the launcher. Launch anything without touching the taskbar.

  • Quick-launch icon grid
  • Add any custom app/executable
  • Preloaded with common system apps
⚙️ Liquid Glass Customization

Make it truly yours

Full live theming — change accent color, glass opacity, corner radius, position, blur, and dark/light mode. Everything applies instantly with no restart. 10 accent presets plus a custom hex picker.

  • 10 accent color presets + custom hex
  • Dark and Light theme modes
  • Glass opacity + corner radius sliders
  • 6 screen position options
  • Live apply — zero restarts
🖥️ Customization Studio

Full App Interface & Island Configurator

Beyond the island settings, DLives ships a full resizable Customization Studio window. Drag to reorder tabs, toggle exactly which modules appear on the floating island, configure glassmorphism presets, manage app launcher shortcuts, and back up your data — all in a dedicated, spacious interface.

🧩 Reorder & toggle island tabs live
🎨 Theme & glassmorphism presets
📍 Island position & physics
💾 System & data backups
🔔 Notifications

Your Windows notifications, unified

DLives captures recent system notifications — WhatsApp, Mail, Windows alerts — and displays them in a live, scrollable feed inside the island. No more alt-tabbing to the Action Center.
