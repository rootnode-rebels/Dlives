Frequently Asked Questions

Quick answers to common questions about DLives installation, permissions, features, and security.

Is DLives free to use? +

Yes, DLives is 100% free with no paywalls, hidden in-app purchases, or telemetry tracking.

Why does Windows SmartScreen display a blue warning during setup? +

Windows Defender SmartScreen displays a warning for newly released or independent executables that are not signed with expensive corporate code-signing certificates. DLives is safe, open, and offline. To install: click "More info" and then click "Run anyway".

Does DLives work on both Windows 10 and Windows 11? +

Yes! DLives is fully compatible with both 64-bit Windows 10 (Build 1903+) and Windows 11. It utilizes native Win32 APIs for acrylic translucency and SMTC media integration.

Where is my personal data and notes stored? +

All user data is stored locally in your roaming profile: %AppData%\DLives\ (e.g. C:\Users\<YourUser>\AppData\Roaming\DLives\). Your notes are saved as plain .txt files that you can open and edit directly in File Explorer or Notepad.

How do I configure DLives to launch on Windows startup? +

Go to the Settings tab inside the expanded island or open the Customization Studio window, and enable the "Start with Windows" toggle. It automatically manages your user registry startup key without requiring administrator permissions.

How do I uninstall DLives? +

You can uninstall DLives like any standard Windows application:

  1. Open Windows Settings → Apps → Installed apps.
  2. Search for DLives and click Uninstall.
  3. Or run the uninstaller directly from %LocalAppData%\Programs\DLives\unins000.exe.
Is there an Android companion app? +

An official Android companion app (DLives.apk) that pairs with your desktop island for synchronized alarms and notifications is currently in active development. Stay tuned for release announcements!

Does DLives require an internet connection? +

No. DLives is completely offline and standalone. No telemetry, analytics, or background internet communication occurs.
