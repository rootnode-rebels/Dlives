Frequently Asked Questions

Quick answers to common questions about Dlives installation, features, performance, and Microsoft Store integration.

How do I get Dlives for Windows? +

You can install Dlives directly with one click from the official Microsoft Store page. Alternatively, a direct standalone installer executable is available on our GitHub Releases page.

Is Dlives free to use? +

Yes, Dlives is 100% free with no paywalls, subscriptions, or telemetry tracking.

Does Dlives work on both Windows 10 and Windows 11? +

Yes! Dlives is fully optimized for 64-bit Windows 10 (Build 1903+) and Windows 11. It utilizes native Win32/DWM APIs for liquid acrylic glassmorphism, SMTC media transport, and taskbar integration.

How does the global F10 hotkey and dragging work? +

Pressing F10 anywhere across Windows immediately toggles the island expanded state or brings it back to the screen. You can also right-click and drag anywhere on the capsule or header to reposition the island to any monitor coordinate, with automatic symmetrical centering.

Where is my personal data and notes stored? +

All user data is stored locally in your user profile at %AppData%\Dlives\. Your notes, alarms, timetable tasks, and settings never leave your PC.

How do I report a bug or suggest a new feature? +
