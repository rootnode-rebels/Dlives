Getting Started with Dlives

Follow this guide to install, launch, and configure Dlives on your Windows 10 or 11 desktop.

System Prerequisites

Before installing, ensure your computer meets these minimum specifications:

  • Operating System: Windows 10 (version 1903 or newer) or Windows 11 (64-bit).
  • Hardware: 100 MB available RAM, ~100 MB free storage space.
  • Permissions: Standard user account (Administrator privileges are not required).
  • Runtimes: None needed. Dlives is self-contained.

Option A: 1-Click Install via Microsoft Store (Recommended)

The fastest and most reliable way to install and keep Dlives updated is directly through the official Microsoft Store:

Option B: Standalone Setup Wizard (.exe)

If you prefer a direct offline installer:

  1. Download the setup executable (Dlives_Setup.exe) from the official GitHub Releases.
  2. Double-click the installer. It installs per-user into %LocalAppData%\Programs\Dlives\ without requiring Windows UAC administrator elevation.

Step 2: First Launch & Basic Usage

Upon launching Dlives:

  • Floating Capsule: A compact glass pill docks at the top edge of your primary monitor.
  • Hover to Expand: Move your mouse pointer over the pill. It expands in 130ms into the liquid glass multi-tab workspace.
  • Global Hotkey: Press F10 anywhere across Windows to toggle the island immediately.
  • Right-Click Drag: Press and hold the right mouse button anywhere on the capsule or header to drag the island smoothly to any monitor location.
  • System Tray: Right-click the Dlives tray icon near the Windows clock to toggle states, open the Customization Studio, or quit.

Step 3: Notifications & WinRT Integration

For Dlives to capture incoming toasts and stream them into the Notifs tab:

Windows Notification Listener
Ensure app notifications are enabled under Windows Settings → System → Notifications. Dlives automatically auto-prunes daily notifications so you start fresh every morning.

Data Storage & Complete Privacy

All your user settings, notes, alarms, and calendar entries remain 100% offline on your device:

User Data Root: %AppData%\Dlives\
├── settings.json       # Visual & behavior configurations
├── timetable.json      # Timetable tasks and scheduler
├── alarms.json         # Alarms & wake-up configurations
├── calendar.json       # Calendar events
└── notes\              # Scratchpad notes readable in File Explorer
