Privacy Policy for Dlives

Effective Date: September 2026 · Fugentech

Privacy by Architecture:
Dlives operates 100% offline. We do not collect, transmit, monetize, or store any personal data on external servers. There is no remote backend, zero telemetry, and zero third-party analytics.

1. Data Collection & Telemetry

Dlives does not collect or transmit any telemetry, diagnostics, keystrokes, personal identifiers, or behavioral data. All operations happen exclusively in memory and within local user configuration files.

2. Local Device Storage

All data created or modified in Dlives — including alarms, timetable entries, notes, calendar schedules, custom preferences, and shelf items — is stored strictly on your local PC in %APPDATA%\Dlives\. This data never leaves your computer.

3. System Permissions & Usage

Dlives utilizes standard Windows APIs for the following desktop features:

  • Windows Notification Listener: Used to display in-app toast summaries and priority popups. All notification contents are processed locally in real time and automatically auto-pruned daily.
  • Media Session API (WinRT): Used to show currently playing tracks (song title, artist, seek position) and provide transport controls (play/pause/seek) for Spotify, Chrome, or Windows Media Player.
  • System Audio & Display APIs: Used solely to adjust system master volume and screen brightness from the Control Center card.

4. Microsoft Store Certified

Dlives complies strictly with Microsoft Store App Developer Agreement and privacy standards, ensuring verified sandboxed execution, seamless updates, and clean uninstallation without residual system bloat.
