Troubleshooting & Data Reset

If you ever need to inspect or reset configuration files:

  1. Close Dlives (Right-click system tray icon near the Windows clock → ❌ Quit Dlives).
  2. Press Win + R, type %AppData%\Dlives and press Enter.
  3. Your preferences (settings.json), task scheduler (timetable.json), and notes are safely stored here.
