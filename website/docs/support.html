Troubleshooting & Data Reset

If the application ever enters an unexpected state, you can inspect or reset configuration files without reinstalling:

  1. Close DLives completely (Right-click system tray icon → Exit).
  2. Press Win + R, type %AppData%\DLives and press Enter.
  3. You can back up or review your settings.json, alarms.json, or notes/ directory.
  4. Deleting settings.json will cause DLives to regenerate fresh default settings on next launch.
